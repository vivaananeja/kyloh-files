IA Explanation Text

EV is the average payoff per hand. If each hand payoff is Xi, then EV = (1/N) * sum(Xi), where win = +1 (or +1.5 for natural blackjack if enabled), loss = -1, and push = 0.

The 95% confidence interval for EV is EV ± 1.96 * (s / sqrt(N)), where s is the sample standard deviation of payoffs.

For the EV difference Delta = EV(S17) - EV(H17), using independent-run approximation: SE(Delta) = sqrt(SE(S17)^2 + SE(H17)^2), so 95% CI = Delta ± 1.96 * SE(Delta).
